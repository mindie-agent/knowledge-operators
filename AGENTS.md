# Operators domain boundaries

This repository contains operator knowledge and evidence only. Keep stable unit
IDs independent of path moves. Parse every unit as `mindie-graded-unit/1`, preserve
its evidence strength and conditions, and rebuild routing metadata after edits.
Runtime code remains in mindie-agent/knowledge.

The current repository is a local draft with formal validator pin pending.
Do not add a contract that falsely implies the old runtime base supports
contract/2. Do not publish or configure installed adapters from this draft.

Preserve unsuccessful results, corrections, provenance and scope limitations.
Do not import private histories or copy the existing vllm-ascend corpus here.
Admit new knowledge individually with the actual source digest and evidence.

A necessary condition whose historical value was not recorded remains `unknown`.
Never make unknown match itself or use a later environment probe to backfill the
original run. Incomplete units are readable for inspection, not automatic reuse.
